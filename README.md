# QORVO CFPH Website Concept — V2

This is a responsive one-page static website concept built for the QORVO CFPH community.

## Files
- index.html
- styles.css
- script.js

## How to open
Double-click `index.html`.

## Before publishing
1. Replace placeholder event dates with real schedules.
2. Replace the TikTok `href="#"` with your TikTok page URL.
3. Replace the placeholder content cards with real posts/news.
4. Add your preferred wording in the footer stating whether QORVO CFPH is official, partnered, or an independent fan/community page.
5. If you have a logo, cover photo, screenshots, giveaway posters, or game-night graphics, add them to an `assets/` folder and I can wire them into the design.

## Recommended hosting
This static version works on Netlify, Cloudflare Pages, GitHub Pages, cPanel hosting, Nginx, or Apache.

## V2 branding
The two supplied QORVO images are included in `assets/` and the wide artwork is now used as the main hero visual. The site accent has been changed from yellow to QORVO neon green.


## Fluid responsive update
This version uses fluid containers, CSS clamp(), auto-fit grids, minmax() columns, and safer mobile breakpoints.
It is specifically adjusted to behave better when zooming in/out on iPhone and Android browsers.
